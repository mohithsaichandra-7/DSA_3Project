SEQUENCELAB FRONTEND

This is a standalone frontend website for the DNA/Protein sequence analysis project.

FILES:
- index.html
- style.css
- script.js

HOW TO OPEN:
1. Extract the ZIP folder.
2. Open index.html by double-clicking it.
3. No installation, npm, Maven, Python server, or other execution is required.

FEATURES:
- Modern responsive UI
- KMP pattern matching
- Z-function pattern search
- Needleman-Wunsch global alignment
- Alignment scoring controls
- Dynamic programming matrix display
- Responsive mobile layout

NOTE:
The website uses Google Fonts when internet is available. The website itself still opens locally without a server.
